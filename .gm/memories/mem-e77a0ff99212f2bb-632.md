thebird window open/close/minimize animations (2026-08-06): wm.css's `.wm-win.wm-min{display:none}` cannot be CSS-transitioned (display has no interpolable intermediate value). Fixed via wm.js's animateMinimize()/animateClose() helpers (design/src/kits/os/wm.js) which apply a wm-minimizing/wm-closing class first, wait for transitionend (220ms fallback timer for safety), THEN apply the real wm-min toggle / el.remove(). theme.css carries the matching keyframes (wm-minimizing/wm-restoring/wm-closing) plus a base .wm-win transition + @starting-style for the open/spawn animation. Respects prefers-reduced-motion:reduce throughout.
